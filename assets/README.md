# assets/

Local, licensed media. The contents are gitignored; only this README is committed.

- `sfx/`: sound effects (Sonniss GDC bundles, Freesound CC0). Every file needs a `licence`.
- `music/`: royalty-free beds with loop points and stings.
- `voices/`: reference clips for the signature voice (own voice, or with written permission).
- `index.sqlite`: the asset index (category, mood, length, loudness, licence). Phase 3.
